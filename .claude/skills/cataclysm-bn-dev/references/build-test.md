# Building and testing

## CMake presets (CMakePresets.json)

| Preset | Use |
| ------ | --- |
| `osx-arm-slim` | macOS ARM dev build (tiles+sound) — the fork Makefile default |
| `linux-slim` | Linux dev build, recommended for contributors (clang/mold/ccache) |
| `linux-full` | Devteam canonical: adds clang-tidy plugin, Tracy, libbacktrace |
| `lint` | Minimal Debug that only builds `json_formatter` (for format targets) |
| `ci-tiles` / `ci-curses` | What CI builds |
| `*-dist` | Release packaging (DMG on macOS, portable tarballs on Linux) |

Configure/build: `cmake --preset <p>` then `cmake --build --preset <p>`
(optionally `--target cataclysm-bn-tiles cata_test-tiles`).
Output: `out/build/<preset>/src/cataclysm-bn-tiles` and
`out/build/<preset>/tests/cata_test-tiles`. Always run binaries from the
repo root so `data/` resolves.

Key cache options: `TILES`, `CURSES`, `SOUND`, `BUILD_SHADERCROSS`
(OFF = use precompiled `data/shaders/`), `BUILD_SDL3` (build SDL3 from
source), `USE_TRACY`, `CATA_CLANG_TIDY_PLUGIN`, `CATA_GPU_VERIFY`
(cross-check GPU compute vs CPU), `LUA_DOCS_ON_BUILD`, `JSON_FORMAT`.
C++ standard is C++23; toolchain needs Clang 22+.

## Shaders / GPU renderer

- 19 HLSL compute kernels in `src/shaders/*_compute.hlsl` — a GPU
  lightmap/visibility system (`src/compute/`: `gpu_platform.cpp`,
  `gpu_lm.cpp`, `gpu_transparency.cpp`; backend selection in
  `compute_backend.h`: hardware GPU / software GPU / CPU).
- shadercross compiles HLSL → SPIR-V + MSL (+ DXIL on Windows) into
  gitignored `data/shaders/`. macOS/Deck can't run shadercross — they
  use precompiled CI artifacts (see fork-workflow.md). After editing an
  .hlsl on macOS, shaders must be regenerated by CI, not locally.
- Runtime override for diagnostics: `--gpu-backend=software` (also
  `vulkan|direct3d12|metal`). CI tests run with software backend.

## Running tests

- From repo root: `./out/build/<preset>/tests/cata_test-tiles "[tag]"`.
  Fork shortcut: `make test`.
- Useful flags: `--rng-seed <n|time>`, `--mods=<m1,m2>`,
  `--user-dir=<dir>` (erased each run), `--option_overrides=n:v`,
  `--error-format=github-action`, `--gpu-backend=software`, tag exprs
  like `"[crafting] ~[slow]"`.
- Fast full suite (Deno sharder, same as CI):
  `build-scripts/run-linux-test-shards.ts --mode file-tags --jobs 4
  --non-slow-shards 8 <test-bin> -- --rng-seed time` — ~3.5 min on a
  12-thread machine. Don't oversubscribe jobs; software-GPU visibility
  tests blow their time budget.
- JSON validation without launching: `<game-bin> --jsonverify` (core),
  `--check-mods [ids…]`, `--check-all-mods`.

## Game binary CLI (dev-useful)

`--seed <s>`, `--world <name>`, `--basepath/--userdir/--datadir/--savedir`
(sandboxing), `--dump-stats`, `--lua-doc <path>`/`--lua-types <path>`
(doc regen), `--dont-debugmsg`, `--paths`. Full list:
`docs/en/dev/reference/cli_options.md` (generated).

## CI (upstream behavior; fork differences in fork-workflow.md)

- `matrix.yml` — main PR/push pipeline: shader artifacts → ci-curses +
  ci-tiles builds → uploads `linux-tiles-x64` playtest tarball → sharded
  tests under Xvfb (only off-main). LLVM 22.
- `autofix.yml` — autofix.ci pushes formatting fixes to PRs
  (`style(autofix.ci): automated formatting`).
- `clang-tidy.yml` — custom plugin over affected files only.
- `i18n-extraction.yml` / `i18n-printf-format.yml` — translation checks.
- `build.yml` — reusable multi-platform build/package (workflow_call).
- Releases: `release.yml` (nightly cron), `experimental-release.yml`
  (push to main), `manual-release.yml` (dispatch).

## Canonical AGENTS.md dev loop (for upstream-facing work)

```sh
cmake --build build --target format          # or file-scoped fmt
cmake --preset linux-full
cmake --build --preset linux-full --target cataclysm-bn-tiles cata_test-tiles
./out/build/linux-full/tests/cata_test-tiles "[filter]"
./build-scripts/lint-json.sh
./out/build/linux-full/src/cataclysm-bn-tiles --check-mods
```
(AGENTS.md's copy of that last command omits the `/src/` segment — the
binary lives under `src/` in every preset's build dir.)
On this fork's Macs, substitute the `osx-arm-slim` preset / `make` targets.
