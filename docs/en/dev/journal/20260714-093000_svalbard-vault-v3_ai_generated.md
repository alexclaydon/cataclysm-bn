# Svalbard vault v3 — megastructure + research-wing storyline

The CDDA mod `svalbard_seed_vault` (in `build-scripts/dda-mods/`) grew from
2×2-OMT levels to 3×3 (72×72 tiles per underground floor, 42-point overmap
special). All maps are generated by `build-scripts/gen-svalbard-mapgen.py`,
which enforces flood-fill connectivity and cross-level stair/ladder alignment;
never hand-edit `mapgen.json`.

Design anchors (absolute coords, same on adjacent levels): surface↔z-1
(11,4)+(12,4); z-1↔z-2 (59,64)+(60,64); z-2↔z-3 (11,49)+(12,49); z-3↔z-4
(59,7)+(60,7). Vent-shaft ladder column at (67,41)/(68,41), closet
(65,38)-(69,42) on every level — ladders alternate tiles per level so each
descent lands on an up-ladder.

Content decisions:

- Surface: grand wedge with flared wings, reinforced-glass art face,
  `t_utility_light` forecourt, signs (`f_sign`/`f_sign_warning` via palette
  `signs`), garage (suv + humvee), fenced radio-mast compound
  (`t_radio_tower`). Three detached warming huts (woodstove + `svalbard_hut`
  cache) are fixed points of the special at offsets (-2,0), (4,2), (1,-2) —
  guaranteed shelter near the vault.
- Story: NPRI-7 containment breach on z-4 (reinforced-glass cell with a gap,
  `fd_blood` field trail running decon → gallery → vent shaft and up through
  every level). Threats are deliberately light: 2 `mon_blob_small` +
  `mon_breather` (z-4), blob (z-3), `mon_zombie_scientist` + `mon_manhack`
  (z-2), manhack (z-1).
- Crafting chains guaranteed via `place_item` (100%): compbow + arrows +
  fire axe (z-2 armory), tailors_kit (z-2 workshop), sewing_kit + thread
  (z-3 laundry), hacksaw, pot/pan (z-3 kitchen); backed by distribution
  groups `svalbard_tailoring` (`@` racks), `svalbard_materials` (`4` crates),
  `svalbard_armory` (`g` gun safes / `i` racks).
- Town proximity: special `city_distance` [3,30], `city_sizes` [4,20] — a
  generated town reliably spawns near the vault (stands in for Longyearbyen;
  actual coastal placement can't be forced from a mod).

Gotchas learned: any furniture char in a palette needs explicit floor terrain
or it sits on `fill_ter` rock; underground special points need per-point
`"locations": ["subterranean_empty"]` or placement fails; `see_cost` is an
enum (`high`/`full_high`/`spaced_high`/…); CDDA consoles are furniture
(`f_console_broken`), rags are `cotton_patchwork`, and vanilla has no
snowmobile or overhead garage door.
